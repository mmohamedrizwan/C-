# AI-901 Practice Questions - Topic 1 (Introduction to AI)

---

## Question 1

A company wants to build an application that can identify whether an uploaded image contains a **cat or a dog**.

**Which AI workload should they use?**

A. Natural Language Processing (NLP)

B. Computer Vision

C. Speech AI

D. Knowledge Mining

### ✅ Answer

**B. Computer Vision**

**Explanation:**
The application analyzes images to identify objects. This is a Computer Vision task.

---

## Question 2

A customer types the following review:

> "The delivery was very slow and the food was cold."

The application should determine whether the review is **Positive, Negative, or Neutral**.

**Which AI workload is being used?**

A. Speech

B. Computer Vision

C. Natural Language Processing (NLP)

D. Object Detection

### ✅ Answer

**C. Natural Language Processing (NLP)**

**Explanation:**
This is an example of **Sentiment Analysis**, which is part of Natural Language Processing.

## Question 3

A company wants to convert recorded customer phone calls into text.

**Which Azure AI capability should they use?**

A. Computer Vision

B. Speech-to-Text

C. Text Analytics

D. Translator

### ✅ Answer

**B. Speech-to-Text**

**Explanation:**
Speech-to-Text converts spoken language into written text.

# AI Workload Identification Tips

| If the Question Mentions... | Choose... |
|------------------------------|-----------|
| Images, photos, cameras | Computer Vision |
| Documents, PDFs, scanned forms | OCR / Document Intelligence |
| Customer reviews, emails, text | Natural Language Processing (NLP) |
| Voice, audio, microphone | Speech AI |
| Predicting future values | Machine Learning |
| Recommendations | Machine Learning |
| Chatbots, AI assistants | Generative AI |
| Content generation | Generative AI |
| Language translation | Translator |
| Voice conversion | Speech Services |

# Exam Tips

- **Images or cameras** → Computer Vision
- **Scanned documents** → OCR / Document Intelligence
- **Customer reviews or emails** → NLP
- **Voice or audio** → Speech AI
- **Prediction or forecasting** → Machine Learning
- **Recommendations** → Machine Learning
- **Chatbots or content generation** → Generative AI
- **Language translation** → Translator
- **Speech conversion** → Speech Services

---

# Key Takeaways

- **Machine Learning** → Predicts outcomes from historical data.
- **Computer Vision** → Understands images and videos.
- **Natural Language Processing (NLP)** → Understands and analyzes text.
- **Speech AI** → Converts speech to text and text to speech.
- **Generative AI** → Creates new content such as text, code, or images.
- **OCR / Document Intelligence** → Extracts text and data from documents.
